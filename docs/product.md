# 日报展示网站产品需求文档

## 1. 产品定位

这是一个用于自动展示 AI 生成日报的轻量网站。网站按日期倒序归档日报内容，当前一期支持两类日报：

- 前端技术
- 金融日报

目标是让用户打开网页后，可以快速看到最新日报、按类别筛选、搜索历史内容，并进入详情查看完整摘要和重点。

## 2. 目标用户

- 需要每天查看金融市场摘要的人
- 关注前端工程化和技术动态的开发者
- 想把 AI 自动生成内容沉淀为可浏览知识库的个人用户
- 需要低成本部署日报站的独立开发者

## 3. 核心功能

### 3.1 首页日报列表

- 按日期倒序展示日报卡片
- 卡片内容包括：
  - 标题
  - 日期
  - 分类
  - 摘要
  - 标签
- 默认选中最新日报

### 3.2 分类筛选

支持三个筛选项：

- 全部
- 前端技术
- 金融日报

### 3.3 搜索

搜索范围包括：

- 标题
- 摘要
- 标签
- 重点摘要
- 详情段落

### 3.4 详情查看

点击日报卡片后，在详情区域展示：

- 标题
- 日期
- 分类
- 摘要
- 标签
- 重点摘要
- 分段详情
- 参考来源链接

### 3.5 数据更新

日报以 JSON 文件形式存放在 `data/reports/`。新增日报后运行生成脚本，自动生成 `public/reports-index.json`，前端读取该索引展示。

## 4. 信息架构

```text
首页
├── 顶部概览
│   ├── 总日报数量
│   ├── 前端技术数量
│   └── 金融日报数量
├── 搜索与筛选
├── 日报列表
└── 日报详情
```

## 5. 非功能需求

- 响应式布局，兼容桌面和移动端
- 静态站部署，无需数据库和服务端运行时
- 数据文件可版本管理，方便回溯
- 构建产物可部署到 Vercel、Netlify、GitHub Pages、Nginx

## 6. 验收标准

- 首页能正常读取 `reports-index.json`
- 日报按日期倒序展示
- 分类筛选生效
- 搜索生效
- 点击卡片可以查看详情
- `npm run generate` 可以生成索引
- `npm run build` 可以成功构建
